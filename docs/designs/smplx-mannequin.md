## Vision

### 10x Check
The 10x version is a **virtual dance teacher** — not a motion capture readout:
- SMPL-X mannequin with anatomically correct body volume, 21 finger joints per hand
- Multi-person tracking with smart auto-focus on the primary dancer
- Joint path trails showing movement trajectory through 3D space
- Per-body-part difficulty breakdown (hands easy, feet hard)
- Formation minimap for group choreo (K-pop, dance crews)
- Beat-synced mannequin glow reinforcing rhythm

### Platonic Ideal
Open Stepwise. Paste a K-pop group dance video. 60 seconds later, you see 7 distinct mannequins on stage, each with their own color. Tap any mannequin to focus. Their hands show every finger position. You slow to 25% speed and the mannequin moves like it's underwater — smooth, weighted, no jitter. A light-painting trail shows where their right hand traveled. The timeline shows difficulty by body section: "hands are easy here, but the footwork is hard." You toggle "mirror mode" and the mannequin faces you like a teacher. You toggle X-ray and see the skeleton underneath.

The feeling: **"It's like having a patient dance teacher who can show me from any angle, at any speed, and never gets tired of repeating."**

## Core Decision: MediaPipe → SMPL-X

MediaPipe gives 24 joint positions (dots). SMPL-X gives full body mesh parameters — 6890 vertices, 127 joints including 21 per hand, body shape estimation. Since Stepwise processes offline on Modal, the ~60-90s processing time (vs ~10s with MediaPipe) is acceptable for dramatically better output.

**Progressive Enhancement Strategy:** Run MediaPipe first (~10s) to show skeleton immediately, then run 4D Humans (~90s) in the background. Frontend auto-upgrades to mannequin when SMPL-X data arrives. User never waits.

**Data Format:** Store compact SMPL parameters (β shape + θ rotations, ~200KB/video) and run SMPL forward pass in the browser to reconstruct vertices. 5MB SMPL model loads once and is cached.

**Person Tracking:** 4D Humans with built-in appearance+motion tracking for persistent person IDs across frames. Handles dancers crossing paths.

Key models considered:
- 4D Humans (HMR 2.0): SMPL mesh + multi-person + global trajectory — CHOSEN
- SMPLify-X / OSX: SMPL-X with hands + face (127 joints)
- WHAM: SMPL + global motion trajectory
- HybrIK: Fast SMPL estimation

## Architecture Decision
**SMPL-X Pipeline** chosen over incremental MediaPipe enhancements:
- Pipeline: yt-dlp → MediaPipe (fast pass) → 4D Humans (full pass) → beat detection → JSON with mesh params
- Frontend: Three.js mannequin renderer using SMPL-X mesh + existing skeleton for X-ray mode
- Multi-person: Separate SMPL-X params per detected person, stored as array
- Schema change: PoseFrame grows from 24 joints to SMPL-X params (β shape, θ rotations)
- Backward compatible: schema version field, old videos render as skeleton

## Blocking Prerequisites — RESOLVED

## Key Architecture Decisions
1. **Progressive enhancement:** Skeleton in 10s, mannequin in 90s
2. **Compact params + browser SMPL layer:** ~200KB/video, 5MB one-time model load
3. **4D Humans with built-in tracking:** Persistent person IDs across frames
4. **Feature flag rollout:** `use_smplx` flag, old MediaPipe path stays intact
5. **Pipeline state machine:** processing → skeleton_ready → upgrading → mannequin_ready
6. **TypeScript SMPL forward pass:** ~200 LOC port, not WebGL shader (engineered enough)
7. **Three implementation phases:** Phase 1 (pipeline), Phase 2 (renderer), Phase 3 (UI enhancements)

## Visual Design Specs (from /plan-design-review)

### Mannequin Material — "Holographic Body Scan"
- Base: `MeshPhysicalMaterial`, `transmission: 0.3`, `roughness: 0.4`, `color: #0a1a2a`
- Emissive: `#00d4ff` at intensity 0.15 (subtle internal glow)
- Wireframe overlay: Fresnel effect — cyan lines at 10% opacity, brighter at mesh edges
- Result: holographic body scan, not store mannequin. Fits "motion capture lab at 2am" mood.

### Multi-Person Color Palette
Primary dancer: #00d4ff (cyan). Others assigned in order:
#ff6b6b (coral), #ffd93d (gold), #6bff8a (mint), #b47aff (lavender), #ff9f43 (amber), #43d9ff (teal)
All tested for contrast on #0a0a0a dark background.

### Skeleton-to-Mannequin Transition
Morph transition: bones thicken into limb volumes, joints expand into body surface.
Duration: 500ms ease-out (DESIGN.md "Long" duration).
The morph communicates "upgrade" viscerally — shows that the mannequin IS the skeleton, evolved.

### Formation Minimap
- Placement: floating overlay, bottom-right of 3D canvas
- Size: ~120x120px (desktop), 100x100px (tablet), dropdown selector on mobile
- Background: #141414 at 80% opacity, rounded corners (8px)
- Dots: 8px circles with glow shadow matching dancer color
- Selected: brighter, 12px. Unselected: dimmer, 8px
- Floor plane: subtle grid (2px lines, #222222)
- Panel label: "FORMATION" — uppercase, Geist Mono 12px
- Only appears for multi-person videos (solo = no minimap)

### Path Trails
- Render trails for hands + feet only (4 joints, not all 24)
- `THREE.Line2` with varying width (thick at current, thin at oldest)
- Cyan with opacity gradient: 1.0 → 0.0 over last 2 seconds
- Subtle bloom/glow via emissive material

### Body-Part Difficulty Heatmap
- Expandable section below main difficulty heatmap on timeline
- Default: collapsed (shows overall). Click "▼ Body parts" to expand
- Three rows: ARMS, LEGS, CORE — labeled in Geist Mono 12px, #888 text
- Uses existing semantic colors: green (#44ff88), yellow (#ffdd44), red (#ff4444)
- 4px gap between rows

### Beat Pulse
- Emissive intensity modulation: base 0.15, peak 0.4 on beat
- Easing: ease-out over 200ms (DESIGN.md "Short" duration)
- Feels like a heartbeat, not a strobe

### Enhancement Badge
- Pill badge on ViewPresetBar: "Enhancing..." in Geist Mono 12px
- Background: #141414, border: #222222 (default) → #00d4ff (on pulse)
- Thin progress bar filling cyan to show SMPL model download + processing
- Subtle 2-second pulse animation. Disappears after morph completes.

### Ghost Mode + Mannequin
Holographic mannequin overlays video (replaces skeleton in ghost mode).
Semi-transparent body over dimmed video — the signature Stepwise visual.
