## Vision

### 10x Check
The Magic Mirror is a tool. The 10x version is a **movement learning platform**:
- Any video → any skill (dance, martial arts, yoga, golf, sign language)
- Creator economy layer (teachers upload choreo, Stepwise generates 3D breakdowns)
- "Stepwise Inside" embeddable widget for other platforms
- Real-time social learning (multiple people viewing + practicing together)

### Platonic Ideal
Open phone → see a dance on TikTok → tap "Learn this" → 5 seconds later, interactive 3D breakdown → mirror mode, phone propped up → skeleton faces you like a teacher → you dance, app scores you in real-time → nail it → tap share → beautiful side-by-side clip posts to your story → friends tap in to try the same dance.

The feeling: **"I can learn any movement I see."**

## Accepted Scope (added to this plan)
- Movement-agnostic branding and UI (don't hardcode "dance")
- Ghost mode: 3D skeleton overlay on original video at 50% opacity
- Loop a section: tap two timeline points to loop
- Speed ramp: auto-increase speed each loop iteration (25% → full tempo)
- Difficulty heatmap: color-coded timeline based on movement complexity
- Hand gesture tracking via MediaPipe Hands (simplified shapes: fist/open/spread/pointing)
- Foot contact detection via pose heuristic (heel/toe/flat/slide/airborne)
- Toggleable detail layers in viewer (body / hands / footwork as separate toggles)

## Architecture Decision
**Decoupled Pipeline** chosen over Monolith MVP:
- Frontend: Next.js + Three.js viewer (Vercel)
- Backend: Python/FastAPI processing service (Modal):
  - yt-dlp → video download
  - MotionBERT → body pose (24 SMPL joints)
  - MediaPipe Hands → hand gestures (21 joints × 2 hands + state classification)
  - Foot contact heuristic → contact type from ankle position/velocity
  - librosa → beat detection
  - Steps 2-5 run in parallel on Modal
- Communication via JSON schema v1.0 (body + hands + feet + beats)
- Reusable API for future features (mobile, social clips, embeddable widget)
