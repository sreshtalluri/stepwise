# services/motion-api/api.py -- the lightweight HTTP layer. Deliberately
# separate from modal_app.py's pinned CV/GPU stack (this process never
# touches CUDA/torch/pymomentum): fastapi + modal client + numpy (to read the
# npz) is the whole dependency surface.
#
#   uv venv --python 3.12 .venv
#   uv pip install --python .venv/bin/python -r requirements-api.txt
#   .venv/bin/python -m uvicorn api:app --port 8811
#
# Also requires packages/motion-contract/python's `motion_contract` package
# to be importable -- api.py adds it to sys.path directly rather than
# packaging this as an installable dependency, since both live in this repo.
#
# And the `ffmpeg` + `ffprobe` BINARIES on PATH (brew install ffmpeg / apt
# install ffmpeg), for the upload fingerprint that skips a GPU reconstruction
# when the same dance has already been processed (fingerprint.py). Not listed
# below because it is not a Python package: it is invoked as a subprocess, not
# linked, so none of ffmpeg's licence terms reach this repo. It is also
# optional -- without it, dedupe falls back to exact-sha256 matching, which
# catches a byte-identical re-upload and nothing else. That degradation is
# logged per upload, never silent.
#
# Deliberately NOT added: any perceptual-hash or video-fingerprint library.
# pHash is GPL-3.0 and videohash is copyleft, both unusable in something that
# ships (docs/research/grounding-models.md §1.5); `imagehash` is BSD-2 but
# would drag in Pillow and scipy for what is four lines of numpy. The two
# hashes are implemented directly in fingerprint.py against numpy, which is
# already here for the npz.
#
# boto3 is the S3 client for Cloudflare R2 (storage.py). No Cloudflare-specific
# SDK: R2 speaks S3, and the whole escape hatch if Cloudflare's CDN terms ever
# become a real block is `rclone sync` to another S3-compatible provider
# (docs/research/infrastructure.md §3). A vendor SDK would quietly spend that.
#
# psycopg is the Postgres driver for the job-state backend (jobstore.py). The
# `pool` extra matters more than it looks: this service scales to zero and back,
# and a fresh TLS handshake on every 2-second job poll is not free. `binary`
# ships a self-contained wheel with libpq vendored, so nothing here needs a
# system library -- which is the property that let it into a Modal image at all.
#
