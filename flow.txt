Stepwise Mesh Platform Restart Flow
===================================

CONTRACT
────────
packages/contracts/schema/mesh-result-v1.schema.json
  - video metadata and signed playback URL
  - people[] with persistent track IDs, colors, confidence, frame coverage, primary-dancer score
  - mesh_asset per successful person: rest-pose body surface, faces, skin weights, joint hierarchy, shape params
  - frames[] with bbox, 2D keypoints, 3D joints, pose params, global transforms, visibility/confidence
  - analysis: beats, difficulty, body-part heatmap, foot contacts, path trails, step segments
  - assets: mesh URLs, optional GLB, debug overlays
  - model_report: adapters, runtime, warnings, license flags

MESH API
────────
POST /v1/jobs
  → validate URL/upload_ref
  → reject > MAX_VIDEO_SECONDS (120 default)
  → enqueue job
GET /v1/jobs/{job_id}
  → queued/downloading/detecting/tracking/meshing/skinning/smoothing/analyzing/packaging/complete/failed
GET /v1/jobs/{job_id}/result
  → MeshResultV1 or partial MeshResultV1 if one person failed
GET /v1/models
  → detector/tracker/mesh adapter descriptors + license flags

PIPELINE
────────
1. Validate and transcode source video.
2. Detect people through PersonDetector adapter.
3. Track persistent IDs through PersonTracker adapter.
4. Recover a full body mesh per track through MeshRecoverer adapter.
5. Smooth identity, global trajectory, pose, and foot contacts.
6. Analyze beats, difficulty, body-part activity, paths, and step segments.
7. Package mesh assets, GLB/debug URLs, and inline metadata.

WEB APP
───────
Landing/upload
  → URL or upload reference, clip-length warning above 60s, hard max 120s
Processing
  → stage rail, progress, people detected, model/license warnings
Viewer
  → video + synchronized multi-person skinned mesh playback
  → primary dancer focus, all-person view, person selector
  → side-by-side, ghost, mirror, front/back, freeze/orbit, formation minimap
  → timeline, beats, speed/loop, difficulty/body-part heatmaps, step markers, hand/foot paths
  → X-ray skeleton as debug overlay only
